Kubernetes 部署更新日期：2026-10-16；其他模块说明核对于 2026-10-07，截图更新于 2026-10-13。当前修改基于 `89d213d`，迁移 head 为 `20260930_0029`。本文档按仓库代码和实际测试记录整理；根目录 README 保留原始题目要求。各轮测试独立记录，不将新部署的功能验收计入历史压测。

平台为不同租户提供 Agent、IM 接入、知识库和远程 MCP。平台管理员配置模型与预算，租户管理员维护自己的 Agent 和机器人。消息通过 PostgreSQL 队列交给 Worker，执行结果持久化后再由 Channel Runtime 回复。

## 容易混淆的操作

- `/ready` 成功不代表整条业务链路可用。它检查主数据库并返回 Worker 数量，数量为 0 也可能返回 200；机器人认证与模型调用还需分别验证。
- 停用保留配置，彻底删除走删除预览和 `/purge`；旧 DELETE 接口保持各自原来的语义，不应一概当作物理删除。
- 文档停用保留文件和向量，彻底删除处理同名文档全部版本；是否完成外部清理以删除收据为准。
- 压测数字、可靠性故障注入和真实 IM 人工观察来自不同轮次，不能合并为一个成功率或生产容量结论。

## 已验证的范围

- 2026-10-16 Kubernetes 适配：默认回归 492 项通过、7 项显式外部检查跳过；另行运行的 5 项集群检查、6 项实际存储场景、6 个真实 LLM/RAG 业务请求通过。测试边界和模型名称见 [Kubernetes 验收记录](Kubernetes验收记录.md)。三个节点共享 Docker Desktop 主机，不代表跨可用区高可用。
- 2026-10-13 默认 `tests/` 回归：475 项通过、2 项外部存储集成跳过。实际服务的 `/health`、`/ready` 均返回 200，采样时有 2 个活跃 Worker；本轮没有重新测量覆盖率。
- 2026-09-28 的完整压测共 4,028 次业务请求：3,908 次模拟任务、120 次真实模型短任务，本轮业务失败为 0。Worker 在同一台 WSL 主机上运行，不是跨机器压测。
- 修复后 18 项可靠性场景通过。投递故障使用本地 HTTP 模拟端，企业微信重连使用真实 SDK 与本地 WebSocket 模拟端；它们与真实 IM 人工验收分别记录。
- 3 个企业微信机器人同群、飞书跨渠道记忆，以及两类冲突知识的 RAG 隔离由项目维护者人工验证。没有建立带样本规模的准确率评测集。
- 2026-09-30 删除功能验收：496 项回归通过（包含 21 项本地删除专项），原跳过的 2 项存储集成另行通过；还完成两个控制台、真实 LLM、RAG 文件与租户清理验证。详情和限制见测试汇总。

详细条件、原始记录位置和局限见[测试结果](测试结果.md)。
