## 当前交付状态

- 已实现平台/租户双管理端、双 IM 长连接、无状态 Worker、共享 Session、RAG、受治理 Tool、知识型 Skill、租户 MCP、可观测与故障恢复。
- 本地模式由主机 Python + uv 运行应用，Docker Compose 只运行基础设施；Kubernetes 模式运行完整平台，两种模式不能同时占用同一组本机端口。
- 2026-09-26 自动化基线为 467 passed、2 skipped、覆盖率 90.09%；外部存储的 2 项集成测试已于上一轮另行通过，Alembic Head 为 `20260924_0028`。本轮真实模型、知识库及管理台浏览器验收通过。
- 生产启用前仍需准备域名与 TLS、外部 Secret Manager、高可用存储、告警接收端和离机备份。

实际行为以代码、Alembic 迁移、`uv.lock` 和自动化测试为准；文档中的“生产建议”不代表本地演示组件已经具备跨可用区高可用能力。
