## 端口与配置

本地入口统一由同一 API 进程提供：`http://127.0.0.1:8000/admin` 与 `/tenant`，接口默认 `/api/v1`。页面从 `/console/config.js` 读取服务端 API 前缀，同源请求自动继承实际主机与端口，不需要另起前端服务。可用 `TRPC_SERVICE_PORT` 和 `TRPC_SERVICE_API_PREFIX` 调整。

新增配置使用 `TRPC_SERVICE_` 前缀：`DATABASE_POOL_SIZE=5`、`DATABASE_MAX_OVERFLOW=5`、`DATABASE_POOL_TIMEOUT=10`、`READINESS_TIMEOUT_SECONDS=2`、`MANAGEMENT_LOGIN_CONCURRENCY=2`、`MANAGEMENT_LOGIN_PER_MINUTE=20`。连接预算是每个 SQL 引擎、每个进程的预算，扩容时需要按进程数计算。登录限流为进程级，分布式入口仍应配置统一限流。
