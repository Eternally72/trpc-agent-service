# 数据库字段字典

核对日期：2026-10-06。依据 `89d213d` 的 SQLAlchemy 元数据整理，目标迁移版本 `20260930_0029`。列出 44 张应用表及 Alembic 版本表。这里只读取模型定义，没有读取真实业务数据，也没有验证某个运行实例的 schema 是否已升级。

设计原因、时序步骤、去重行为及拆表关系见 [存储表结构设计](存储表结构设计.md)。本文按表名字母顺序查字段，使用 PostgreSQL 类型；字段默认值为 `—` 表示该层未声明默认值，不代表运行时一定不赋值。

“应用默认”由 ORM 插入流程设置，“数据库默认”在数据库收到未提供该列的 INSERT 时生效。直接写 SQL 不会自动执行 Python 默认函数。常见 created_at / updated_at 表示创建和更新时间；ORM 的 updated_at 自动更新行为不是数据库 UPDATE 触发器。

`UUID` 是标识；`TIMESTAMP WITH TIME ZONE` 是带时区时间；`JSON/JSONB` 保存结构化配置或载荷；`NUMERIC(20,8)` 保存十进制定点数；`VECTOR(1024)` 保存 1024 维向量。可空为“否”的字段必须获得一个非 NULL 值。

外键部分只列真正声明在 ORM 中的约束。具有 tenant_id、request_id 或其他相似字段，并不意味着已经存在外键。唯一约束和唯一索引会去重，普通索引不会。PostgreSQL 普通 UNIQUE 中 NULL 不视为彼此相同。
